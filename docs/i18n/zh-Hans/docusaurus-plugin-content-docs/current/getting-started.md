# 快速上手

先构建一个小型 evjs 应用，再了解让大型项目保持可预测的文件约定。

## 从这里开始

1. 跟随[快速开始](./quick-start)，创建两个页面、加入服务端代码，并完成一次生产构建。
2. 阅读[项目结构](./project-structure)，确定页面、共享代码、API 路由和配置应该放在哪里。
3. 需要嵌套或动态路由时，继续阅读[页面与路由](./client-routes)。

## 准备工作

- 仓库当前支持的 Node.js 版本。
- React 以及 TypeScript 或 JavaScript 基础。
- 项目支持的包管理器。

在渲染第一个页面前，你不需要配置路由器、创建浏览器入口或选择构建器。evjs 从你编写的项目文件开始，只在行为确实需要变化时才增加配置。

直接选择与你下一个任务对应的指南：
