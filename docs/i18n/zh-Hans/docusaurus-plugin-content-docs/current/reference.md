# 参考

当你已经知道要构建什么，只需查询准确字段、文件名、命令或约束时，使用参考页。

| 参考 | 内容 |
| --- | --- |
| [配置](./config) | `ev.config.ts`、路由、服务端、开发、输出、传输、插件与构建器选择 |
| [文件约定](./file-conventions) | 框架识别的页面、API 路由、中间件、布局与生成文件名 |
| [项目结构](./project-structure) | 完整约定矩阵与推荐的目录职责 |
| [自定义路由与运行时](./advanced-conventions) | 关闭文件约定与直接使用运行时 |

参考页描述受支持的契约。如果需要带有工作路径的引导式说明，请从[使用指南](./guides)开始。
