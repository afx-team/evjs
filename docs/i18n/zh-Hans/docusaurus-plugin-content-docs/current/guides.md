# 使用指南

这些指南围绕构建和交付 evjs 应用中的具体任务组织。每篇指南都从你需要编写的公共 API 或文件开始，并链接到提供完整字段说明的参考页。

## 构建用户体验

- [页面与路由](./client-routes)——创建页面、嵌套路由、布局、动态路径和导航。
- [渲染](./rendering)——逐页选择 CSR、SSR、SSG、PPR 或 RSC。
- [使用插件](./plugins)——安装集成，并在整个应用或单个页面中配置。

## 增加服务端能力

- [服务端函数](./server-functions)——从应用代码调用带类型的服务端操作。
- [API 路由与中间件](./server-routes)——暴露 HTTP 端点并组合请求中间件。

## 开发与交付

- [本地开发](./dev)——运行应用，配置端口、代理并诊断变更。
- [构建](./build)——检查应用并生成生产产物。
- [部署](./deploy)——选择静态、Node.js、Edge 或前后端分离托管。
- [Qiankun](./qiankun)——把 evjs 应用组合为微前端。

需要查询准确选项或文件名？前往[参考](./reference)。
