# Guides

Task-oriented guides for building and shipping an evjs application. Each guide
starts with the public API or file you author and links to reference material
for exhaustive details.

## Build the user experience

- [Pages and Routing](./client-routes) — create pages, nested routes, layouts,
  dynamic segments, and navigation.
- [Rendering](./rendering) — choose CSR, SSR, SSG, PPR, or RSC per page.
- [Plugins](./plugins) — install an integration and configure it for the whole
  app or for one page.

## Add server capabilities

- [Server Functions](./server-functions) — call typed server-side operations
  from application code.
- [API Routes and Middleware](./server-routes) — expose HTTP endpoints and
  compose request middleware.

## Develop and ship

- [Local Development](./dev) — run the app, configure ports and proxies, and
  diagnose changes.
- [Build](./build) — inspect the application and create production output.
- [Deployment](./deploy) — choose static, Node.js, edge, or split hosting.
- [Qiankun](./qiankun) — compose evjs applications as micro-frontends.

Looking for an exact option or filename? Go to the [Reference](./reference).
